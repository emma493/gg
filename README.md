# GG Project

Admin dashboard and user page for GG project.

## Structure

- `gg-admin/` — React admin dashboard (login, claim seat, dashboard, analytics)
- `shatta-wale/` — Static user page (₵200 birthday giveaway)

## Deployed URLs

- `https://claimprizes.netlify.app/gg-admin/login` — Admin login
- `https://claimprizes.netlify.app/gg-admin/dashboard` — Admin dashboard
- `https://claimprizes.netlify.app/shatta-wale` — User page

## Build

```bash
npm install
npm run build  # Builds both gg-admin and shatta-wale to dist/
```
